# `Espace Job Board: Plateforme de Recrutement Full-Stack Moderne & Sécurisée`

```
Architecture 3-tiers découpée en deux modules principaux (Client/Serveur) :

1. backend (API REST Java 17 / Spring Boot / Kafka)
2. frontend (Application React Vite).

```
## `Prérequis`

```
Backend
- Java 17
- Spring Boot 3.5
- Flyway 11.7.2
- JUnit/Mockito 5.17
- Log4j 2.24
- Kafka 3.9.2

Bases de données
- PostgreSQL 16 (Développement / Production sur Neon)

Frontend
- React 19
- Lucide-react 1.54
- Material UI 9.5

```
